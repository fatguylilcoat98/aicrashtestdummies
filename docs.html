What the system does

AI Crash Test Dummies is an investigation process with six public identities. It is not six chatbots voting.

Running today, inside the existing engine

  • A repository zip can be ingested and indexed. Paths are normalized. Each file is hashed.
  • Search and symbol cross-reference return a shared receipt. The same bytes keep the same receipt id.
  • If the same path later hashes differently, the result is a source conflict. Neither copy is chosen quietly.
  • Candidates can be committed without showing them to other seats first.
  • Gate Zero returns pass, fail, or unresolved. Fail and known issues stop the candidate.
  • The seat who discovered a candidate cannot be its falsifier.
  • An open decisive contradiction blocks confirmation. Production claims without version and deployment verification are blocked.

Not available yet

  • Public accounts, sign-in, and self-serve upload on this website.
  • A customer dashboard, crash-report archive, or billing.
  • Sandboxed compilation, forked-chain tests, and executable proof receipts.
  • Automatic deployment matching against production bytecode.
  • A finished known-issue search across audits, issues, and the public web. The engine can record a known issue and stop on an exact symbol-and-path match. It does not yet crawl the outside world.

How a crash test is supposed to move

Submit. Investigate. Challenge. Test. Report. Search comes before a theory. Reachability comes before severity. A disproved path stays in the record.
